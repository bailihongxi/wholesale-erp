六、响应式自动适配

📱 手机模式（窗口宽度 < 768px）

→ 底部 Tab 导航 + 单列卡片布局，单手操作友好

💻 电脑模式（窗口宽度 ≥ 768px）

→ 左侧固定导航栏 + 表格/多列布局，办公效率更高

🔄 自动切换

→ Vue 响应式组件监听窗口宽度，同一套代码自动切换布局

💾 状态记忆

→ 侧边栏折叠状态、登录账号、数据全部自动保存，刷新/关闭不丢失
