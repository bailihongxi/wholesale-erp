# 批量并行性能优化规范（V2.0-18）

## 问题背景

V2.0 迁移到 Supabase（新加坡节点）后，每次数据库操作都是一次 HTTP 请求到云端。原来的代码在循环里逐条查询/写入，N 个商品就要 N×5 次串行请求，手机网络下 3-6 秒才能完成入库。

## 优化原则

**能批量就不循环，能并行就不串行。**

### 1. 查询阶段：一次性批量查出所有需要的数据

**错误写法（串行 N 次请求）：**
```ts
for (const item of items) {
  const prior = await db.stockRecords.where('refOrderId').equals(orderId).filter(...).toArray()
  const stock = await db.stock.where('productId').equals(item.productId).first()
  await inv.applyLocationDelta(item.productId, locId, actual)
  await db.stockRecords.add({...})
}
```

**正确写法（3 次并行请求）：**
```ts
// 一次性查出所有
const productIds = items.map(it => it.productId)
const [allRecords, allStocks, allLocStocks] = await Promise.all([
  db.stockRecords.where('refOrderId').equals(orderId).toArray(),
  db.stock.where('productId').anyOf(productIds).toArray(),
  db.locationStock.where('productId').anyOf(productIds).toArray(),
])
// 用 Map 在内存里查找
const stockMap = new Map(allStocks.map(s => [s.productId, s]))
```

### 2. 写入阶段：收集后并行批量写

```ts
const stockToUpdate = [], recordsToAdd = []
for (const item of items) {
  // 在内存里计算，不发请求
  stockToUpdate.push({...})
  recordsToAdd.push({...})
}
// 一次性并行写入
await Promise.all([
  ...stockToUpdate.map(u => db.stock.update(u.id, {...})),
  recordsToAdd.length ? db.stockRecords.bulkAdd(recordsToAdd) : Promise.resolve(),
  db.purchaseOrders.update(orderId, { status: ... }),
])
```

### 3. 列表查询：循环里查关联表 → 批量查

**错误：**
```ts
for (const r of records) {
  const p = await db.products.get(r.productId)  // 每条都查一次
}
```

**正确：**
```ts
const productIds = [...new Set(records.map(r => r.productId))]
const allProducts = await db.products.where('id').anyOf(productIds).toArray()
const productMap = new Map(allProducts.map(p => [p.id, p]))
// 循环里用 Map.get()，不发请求
```

## 已优化的函数

| 文件 | 函数 | 优化前 | 优化后 |
|---|---|---|---|
| stores/purchase.ts | inbound() | 15+ 次串行请求 | 5 次并行 |
| stores/sales.ts | outbound() | 15+ 次串行请求 | 5 次并行 |
| stores/purchase.ts | listInboundHistory() | 循环逐个查商品 | 1 次批量查 |
| stores/sales.ts | listOutboundHistory() | 循环逐个查商品 | 1 次批量查 |
| stores/stockDoc.ts | getDoc() | 循环逐个查商品 | 1 次批量查 |

## 以后新功能开发注意

写任何 store 函数时：
1. 先想清楚需要查哪些表
2. 所有查询用 `Promise.all` 并行发出
3. 用 `anyOf(ids)` 代替循环 `get(id)`
4. 写入先收集到数组，最后 `Promise.all` 并行写
5. 流水用 `bulkAdd` 代替循环 `add`
