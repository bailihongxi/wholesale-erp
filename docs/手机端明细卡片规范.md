# 手机端明细卡片规范（全项目唯一口径）

> 最后更新：2026-09-24　｜　适用版本：**V2.1-1.3 起写死**　｜　老板 2026-09-24 指令
> 一句话：**电脑端商品明细一律「列表」，手机端商品明细一律「卡片」** —— 这条规定写死，
> 所有模块（销售、采购、报价、预采询价、出入库……）一律照此实现，不许各页各写一套。

---

## 1. 规定（照抄执行）

| 端 | 商品明细用什么 | 判据 | 具体形态 |
| --- | --- | --- | --- |
| **电脑端 ≥768px** | **列表样式** | `!isMobile` | `<table class="data-table">` 或页面自己的行列表（如销售单详情的 `.mc-list`） |
| **手机端 <768px** | **卡片模式** | `isMobile` / `.app-layout.is-mobile` | **只读** → 用 `components/ui/ItemCards.vue`；**可编辑** → `@media (max-width:767px)` 把表格转卡片 |

**为什么写死**：手机端宽度只有 390px，多列数字表格无论怎么排都会「撑破屏幕」——
过去每加一个页面、每加一列，都要重新修一遍横向溢出。收敛成「一条规定 + 一个组件」后，
新模块只要挂组件/加类，就自动不会撑破。

---

## 2. 只读明细 → 用组件（唯一模板）

`src/components/ui/ItemCards.vue` —— 手机端商品明细卡片，全站唯一实现。

```vue
<section class="block">
  <!-- 手机端：卡片 -->
  <ItemCards
    v-if="isMobile"
    title="商品明细"                 <!-- 组件自动补「（N）」 -->
    :items="cardRows"               <!-- ItemCardRow[]，见 src/types/index.ts -->
    :show-price="canSeeAnyPrice"    <!-- 库房/无权看价传 false -->
    :total-qty="totalQty"           <!-- 传则优先；不传按明细求和 -->
    :total-amount="order?.totalAmount ?? 0"
    empty-text="暂无明细"
  />

  <!-- 电脑端：列表（原样保留，别改成卡片） -->
  <template v-else>
    <h4 class="block-title">商品明细（{{ items.length }}）</h4>
    <table class="data-table">…</table>
  </template>
</section>
```

页面只负责把业务明细折算成统一形状（**不要在组件里耦合业务字段**）：

```ts
import ItemCards from '../../components/ui/ItemCards.vue'
import type { ItemCardRow } from '../../types'
import { useResponsive } from '../../composables/useResponsive'

const { isMobile } = useResponsive()

const cardRows = computed<ItemCardRow[]>(() =>
  items.value.map(it => ({
    name: nameOf(it.productId),
    unit: unitOf(it.productId),
    qty: it.quantity,
    price: it.price,
    amount: it.subtotal,
    tag: it.isGift ? '🎁 赠品' : undefined,        // 名称后的角标
    note: it.isGift ? '赠品不计价' : undefined      // 代替「× 单价 = 金额」
  }))
)
```

**组件已具备的观感（效果图口径，别改）**：
左侧蓝竖条标题「商品明细（N）」→ 内层白底描边卡片（商品名深色加粗独占一行）→
`1 套 × ¥37,950.00 =` 灰色小字 + 右侧金额**深色加粗** → 底部虚线分隔的合计条
「合计 1 件」+ **红色大号**合计金额。

**已接线的页面**：

| 页面 | 手机端卡片标题 | 电脑端保留的列表 |
| --- | --- | --- |
| `sales/SaleOrderDetailView.vue` 销售单详情 | 商品明细 | `.mc-list` 行列表 |
| `sales/QuotesView.vue` 报价单详情 | 报价明细 | `.data-table` 表格 |
| `purchase/PurchaseOrderDetailView.vue` 采购单详情 | 商品明细 | `.item-table` 表格 |
| `purchase/PurchaseQuotesView.vue` 预采询价详情 | 询价明细 | `.data-table` 表格 |

## 3. 可编辑明细 → 页面 `@media` 转卡片（唯一范式）

开单 / 编辑态带输入框，不用组件（组件化要把两套 DOM 都维护一遍、还要同步输入框状态），
统一用**固定的 CSS 范式**：给表格加契约类 `items-edit`，列序写进 `thead` 注释。

```css
@media (max-width: 767px) {
  .tb-scroll { overflow-x: visible; }              /* 卡片不超宽，别再横滑 */
  .items-edit, .items-edit tbody { min-width: 0; } /* 解除「表格至少 640px」约束 */
  .items-edit thead { display: none; }
  .items-edit, .items-edit tbody, .items-edit tr, .items-edit td { display: block; width: 100%; }
  .items-edit tbody tr {
    display: flex; flex-wrap: wrap; align-items: center; gap: 6px 10px;
    background: #f8fafc; border-radius: 10px; padding: 10px 12px; margin-bottom: 8px;
  }
  .items-edit tbody td { padding: 2px 0; border: none; width: auto; }
  .items-edit tbody td:nth-child(1) { display: none; }                    /* 序号 */
  .items-edit tbody td:nth-child(2) { width: 100%; font-size: 15px; font-weight: 600; order: 1; }
  /* …其余列按 order 重排（见下表）… */
  .items-edit .mini-input { width: 64px; height: 30px; }

  /* ⚠️ 空态行只有一个 td（colspan）→ 会被 nth-child(1) 的 display:none 一起隐藏，
     手机端就变成一张空卡片。必须显式放回来（同特异性、靠书写顺序取胜）。 */
  .items-edit tbody td.empty { display: block; width: 100%; }
}
```

### 列序契约（往明细插列必须同步改 CSS）

| 页面 | 契约类 | 列序（`nth-child`） |
| --- | --- | --- |
| `PurchaseCreateView` 采购商品明细 | 无自定义类 | 1序号 2名称 3类别 4单位 5库存 6数量 7进价 8金额 9赠品 10移除 |
| `SalesCreateView` 销售商品明细 | 无自定义类 | 同上（5 为可用库存） |
| `QuotesView` 新建态 报价商品明细 | `.items-edit` | 1序号 2名称 3类别 4单位 5数量 6报价 7金额 8操作 |
| `PurchaseQuotesView` 新建态 询价商品明细 | `.items-edit` | 1序号 2名称 3类别 4单位 5数量 6询价 7金额 8操作 |
| `ProductPicker` 选商品弹窗 | `.picker .data-table` | 与开单页同构 |

> 详情态的 `.items-view`（旧的 nth-child 拆表）**已随 V2.1-1.3 删除**，不要再补回来 —— 详情态走组件。

## 4. 落地前必查四项（照做，别只跑构建）

1. `document.documentElement.scrollWidth - clientWidth === 0` —— **没有横向溢出**（撑破屏幕的唯一客观判据）；
2. 长商品名（如 `HF-250LW/TS06SJD`）在卡片里能折行，不顶出屏幕；
3. **空态可见**：没加商品时能看到「暂无明细 / 尚未添加商品」，不是一张空卡片；
4. 价格类字段受权限控制：库房 / 经销商无权看价时 `:show-price="false"`，只留数量。

验法：切 390 宽（`agent-browser set viewport 390 844` + `location.reload()`）读计算样式 / DOM，别靠肉眼截图。
