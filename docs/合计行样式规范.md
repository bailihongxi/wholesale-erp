# 合计行样式规范（V2.0-18 确立）

## 问题背景

手机端各明细页的合计行（tfoot）长期存在两个问题：
1. **列不对齐**：全局 CSS 把 `.data-table` 拆成 `display: block`，thead/tbody 是 `display: table; min-width: 640px`，tfoot 被设成 `display: block; flex`，导致 tfoot 列宽和 thead/tbody 对不上，合计数字错位。
2. **颜色被覆盖**：全局 `.data-table tfoot td { color: var(--c-primary) }`（深蓝色）把数据行的状态色（绿/橙/红）覆盖了。

## 最终方案

### 1. 表格布局：保持标准 table，不拆 block

在 `src/styles/theme.css` 手机端 `@media (max-width: 767px)` 里：
- **不写** `.data-table { display: block }`
- **不写** `thead/tbody { display: table; min-width: 640px }`
- **不写** `tfoot { display: block; flex }`

表格保持默认 `display: table`，在 `.tb-scroll` 里 `overflow-x: auto` 横向滚动。thead/tbody/tfoot 是同一个 table，列宽自动对齐。

### 2. 合计行文字样式（写在各页面 `<style scoped>` 里）

```css
/* "合计"标签：居左对齐商品名称列，字体加大 */
.total-label {
  text-align: left;
  padding-left: 48px;  /* 对齐序号列宽度 */
  font-size: 16px;
  font-weight: 700;
}

/* 合计行所有 td：字体加大 */
.data-table tfoot td {
  font-size: 16px;
  font-weight: 700;
}

/* 状态色覆盖：合计行数字颜色和上方数据行一致 */
.data-table tfoot td.stock-ok   { color: var(--c-success) !important; }
.data-table tfoot td.stock-low  { color: var(--c-warning) !important; }
.data-table tfoot td.stock-out  { color: var(--c-danger)  !important; }
```

### 3. tfoot HTML 结构

保持标准 table 结构，不要把 tfoot 从 table 里拿出来：

```html
<table class="data-table">
  <thead>...</thead>
  <tbody>...</tbody>
  <tfoot v-if="items.length">
    <tr>
      <td colspan="3" class="total-label">合计</td>
      <td class="num">{{ orderedTotal }}</td>
      <td class="num stock-ok">{{ receivedTotal }}</td>
      <td class="num stock-low">{{ remainTotal }}</td>
      <td class="num">{{ thisTotal }}</td>
      <td></td>
    </tr>
  </tfoot>
</table>
```

## 各列颜色对照

| 列 | 数据行颜色 | 合计行 class |
|---|---|---|
| 订购量 / 数量 | 黑色（默认） | `num` |
| 已收 | 绿色 | `num stock-ok` |
| 待收 | 橙色（有待收量时） | `num stock-low` |
| 本次实收 | 黑色（默认） | `num` |
| 金额 | 深蓝（默认） | `num` |

## 适用页面

目前已应用：入库验货明细（InboundDetailView）。

其他单据页需要修改合计行时，按上述方案执行：
1. 保持 table 布局，不拆 block
2. 加 `.total-label` 居左加大
3. 加 `.data-table tfoot td` 字体加大
4. 按列加 `stock-ok` / `stock-low` 等状态色 class
5. 在 scoped style 里加颜色覆盖规则

## 禁忌

- ❌ 不要在全局 CSS 里把 `.data-table` 拆成 `display: block`
- ❌ 不要把 tfoot 从 table 里拿出来做成独立 div（会导致列不对齐）
- ❌ 不要用 `margin-left: auto` 把合计数字推到右边（会和列错位）
